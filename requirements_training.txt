# ---------------------------------------------------------------------------
# Jetson Orin inference note
# ---------------------------------------------------------------------------
# PyTorch for Jetson Orin MUST be installed from NVIDIA's JetPack wheel —
# NOT from PyPI — to get CUDA GPU support.
#
# 1. Install JetPack 6.x via SDK Manager (or apt):
#    sudo apt install nvidia-jetpack
#
# 2. Install the matching PyTorch wheel from NVIDIA:
#    https://developer.download.nvidia.com/compute/redist/jp/v61/pytorch/
#
#    Example (JetPack 6.1, Python 3.10):
#    pip install torch-2.3.0-cp310-cp310-linux_aarch64.whl
#
# 3. torchvision and h5py can be installed from PyPI normally:
#    pip install torchvision h5py einops
#
# 4. torchvision may need to be built from source on aarch64 if no
#    matching wheel is available:
#    pip install torchvision --no-binary torchvision
