    Sweep each joint by hand

    Move one joint at a time to each end of its travel and hold it there for a moment. An end counts once two consecutive readings agree, so a bump or a flick cannot widen a limit. Confirm each joint, then save.

    LEADER RANGES · READ ONLY

    Sweep each leader joint

    Move each leader joint, and each gripper trigger, all the way to both ends of its travel, confirm it, then save. Teleop scales each leader range onto its robot joint's range from the leader zero: hold the leaders in the robot's reference pose (arms straight down, triggers released) and set the zero. You can set it again here or in Teleop (Z) at any time.
