What this view means

Six schematic arm links and a separate hinged gripper trigger show the seven encoder channels. Arrows mark positive rotation about each configured axis.

Raw values are encoder radians. Display angles are direction × (raw − reference), without wrapping. Capture and flip edit only this viewer's software mapping.

This tool cannot command leader or follower motors. It does not validate collision protection or teleoperation readiness.
